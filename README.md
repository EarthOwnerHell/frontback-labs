# Практическая работа 1‑2

В этом репозитории собраны результаты практических заданий по работе с API и инструментами тестирования.

## 1. Тестирование собственного API (Практическое занятие 2)

1. Запуск сервера
   ```bash
   # пример запуска (зависит от реализации API)
   node practise2/index.js
   ```
2. Тестирование с помощью Postman
   - выполнено **не менее трёх запросов** к реализованному API
   - в качестве примера запросов использовались следующие эндпоинты:
     1. `GET /items` — получение списка элементов
     2. `POST /items` — добавление нового элемента
     3. `DELETE /items/:id` — удаление элемента по идентификатору
   - скриншоты результатов тестирования (встроены ниже):

## 2. Работа с публичным API

1. **Выбор API:** открыт API для получения информации о погоде (пример)
2. **Получение ключа:** зарегистрировался на сайте, получил API‑ключ и сохранил его в
   переменной окружения или `.env`
3. **Изучение документации:** ссылка на документацию
   – [https://example-weather-api.com/docs](https://example-weather-api.com/docs)
4. Выполнено **не менее пяти запросов**:
   - `GET /current?city=London` — текущее состояние погоды
   - `GET /forecast?city=Paris&days=3` — прогноз на 3 дня
   - `GET /alerts?region=EU` — текущие предупреждения
   - `POST /subscribe` — подписка на уведомления
   - `DELETE /subscribe/:id` — отмена подписки
